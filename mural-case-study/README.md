# Mural — Experts on Demand (case study)

Next.js App Router + Tailwind. Primary content: `content/mural-case-study.md` (YAML frontmatter + markdown sections).

## Develop

```bash
cd mural-case-study
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy (Vercel)

Set **Root Directory** to `mural-case-study` (if the Git repo is the parent `Portfolio/` folder), or deploy this folder as its own repository.

Framework preset should remain **Other** / static; `package.json` defines the Next build.
